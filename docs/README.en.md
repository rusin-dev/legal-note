#### What's this?

This project is a local note-taking software with Markdown support. Features include:

* Real-time Markdown rendering
  * Including $\LaTeX$ and code highlighting for mainstream languages
* Note repository sync with GitHub/Gitee
* UI built on Python Flet
* AI copilot
* Third-party plugin / theme loading
