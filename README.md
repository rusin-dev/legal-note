#### What's this? | 这是什么？

本项目是一个支持 Markdown 的本地笔记软件。支持的特性包含：
* Markdown 即时渲染
  * 包含 $\LaTeX$ 以及主流语言的代码高亮
* Github/Gitee 的笔记仓库同步
* 基于 Python Flet 构建的 UI 界面
* AI 副驾驶
* 第三方插件 / 主题加载
